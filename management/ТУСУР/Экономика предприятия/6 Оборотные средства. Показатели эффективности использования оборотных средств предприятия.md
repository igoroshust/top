# 6 Оборотные средства. Показатели эффективности использования оборотных средств предприятия

## Определение

**Оборотные средства** — это совокупность денежных средств, авансированных для создания оборотных производственных фондов и фондов обращения, обеспечивающих непрерывность процесса производства и реализации продукции.

Оборотные средства находятся в постоянном движении, совершая кругооборот: Деньги → Запасы → Производство → Готовая продукция → Деньги.

---

## Состав и структура оборотных средств

```
ОБОРОТНЫЕ СРЕДСТВА
    │
    ├── ОБОРОТНЫЕ ПРОИЗВОДСТВЕННЫЕ ФОНДЫ (сфера производства)
    │   ├── Производственные запасы (сырьё, материалы, топливо, запчасти)
    │   ├── Незавершённое производство (продукция, не прошедшая все стадии)
    │   ├── Расходы будущих периодов (затраты, произведённые в текущем периоде, но относящиеся к будущим)
    │
    └── ФОНДЫ ОБРАЩЕНИЯ (сфера обращения)
        ├── Готовая продукция на складе
        ├── Товары отгруженные (в пути)
        ├── Дебиторская задолженность (долги покупателей)
        ├── Денежные средства (касса, расчётный счёт, валютный счёт)
        └── Краткосрочные финансовые вложения
```

### Структура оборотных средств (пример для промышленности)

| Элемент | Примерная доля |
|---------|----------------|
| Сырьё и материалы | 30–40% |
| Незавершённое производство | 15–25% |
| Готовая продукция | 10–15% |
| Дебиторская задолженность | 15–25% |
| Денежные средства | 5–10% |

---

## Кругооборот оборотных средств

```
Д — Т (производственные запасы) — П (производство) — Т' (готовая продукция) — Д' (деньги с прибылью)
│                                                                                      │
└────────────────────── Один оборот ──────────────────────────────────────────────────┘
```

### Стадии кругооборота

| Стадия | Что происходит | Форма |
|--------|---------------|-------|
| **1. Снабжение** | Закупка сырья и материалов | Деньги → Запасы |
| **2. Производство** | Использование запасов, создание продукции | Запасы → Незавершёнка → Готовая продукция |
| **3. Сбыт** | Реализация готовой продукции | Готовая продукция → Деньги + Прибыль |

---

## Нормирование оборотных средств

**Нормирование** — это установление экономически обоснованных нормативов оборотных средств, обеспечивающих бесперебойную работу предприятия.

### Методы нормирования

| Метод | Описание |
|-------|----------|
| **Метод прямого счёта** | Расчёт по каждому элементу на основе норм |
| **Аналитический метод** | Корректировка фактических остатков |
| **Коэффициентный метод** | Умножение норматива на коэффициент роста |

### Норматив производственных запасов

```
Нпз = Рсут × Тнорм
```
Где:
- Рсут — среднесуточный расход материала;
- Тнорм — норма запаса в днях (текущий + страховой + подготовительный).

### Норматив незавершённого производства

```
Ннп = Ссут × Тц × Кнз
```
Где:
- Ссут — среднесуточные затраты на производство;
- Тц — длительность производственного цикла;
- Кнз — коэффициент нарастания затрат.

### Норматив готовой продукции

```
Нгп = Гсут × Тподг
```
Где:
- Гсут — среднесуточный выпуск;
- Тподг — время подготовки продукции к отгрузке.

## Показатели эффективности использования оборотных средств

### 1. Коэффициент оборачиваемости

```
Коб = РП / ОбСср
```
Где:
- РП — реализованная продукция за период (руб.);
- ОбСср — средний остаток оборотных средств (руб.).

**Показывает:** количество оборотов, совершаемых оборотными средствами за период.

### 2. Длительность одного оборота

```
Доб = Дп / Коб = (ОбСср × Дп) / РП
```
Где:
- Дп — число дней в периоде (360, 90, 30).

**Показывает:** средний срок возврата средств в денежную форму (в днях).

### 3. Коэффициент загрузки оборотных средств

```
Кз = ОбСср / РП
```
**Показывает:** сколько оборотных средств приходится на 1 рубль реализованной продукции (обратный показатель оборачиваемости).

### 4. Рентабельность оборотных средств

```
Rобс = (П / ОбСср) × 100%
```
**Показывает:** прибыль на 1 рубль оборотных средств.

---

## Нормативные значения показателей

| Показатель | Тенденция | Эффективно |
|------------|-----------|------------|
| Коэффициент оборачиваемости | ↑ Рост | Больше оборотов |
| Длительность оборота | ↓ Снижение | Быстрее возврат |
| Коэффициент загрузки | ↓ Снижение | Меньше загрузка |
| Рентабельность ОбС | ↑ Рост | Выше доходность |

---

## Пути ускорения оборачиваемости оборотных средств

| Стадия | Мероприятия |
|--------|-------------|
| **Снабжение** | Оптимизация запасов, сокращение интервалов поставок |
| **Производство** | Сокращение производственного цикла, снижение трудоёмкости |
| **Сбыт** | Ускорение отгрузки, работа с дебиторской задолженностью |
| **Управление** | Контроль за движением средств, финансовое планирование |

---

## Эффект от ускорения оборачиваемости

```
Э = (Доб1 — Доб0) × (РП / Дп)
```
Где:
- Доб1, Доб0 — длительность оборота в отчётном и базисном периодах;
- РП — реализованная продукция в отчётном периоде.

**Положительный эффект:** высвобождение средств из оборота (абсолютное или относительное).

---

## Вывод

Оборотные средства обеспечивают непрерывность производственного процесса. Их эффективность характеризуется скоростью оборота: чем быстрее средства проходят кругооборот (выше Коб, меньше Доб), тем меньше требуется средств для обеспечения производства. Ускорение оборачиваемости — один из главных резервов повышения эффективности предприятия.
