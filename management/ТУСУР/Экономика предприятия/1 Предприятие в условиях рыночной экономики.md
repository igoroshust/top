# 1 Предприятие в условиях рыночной экономики

## Определение

**Предприятие** — это самостоятельный хозяйствующий субъект, созданный для производства продукции, выполнения работ или оказания услуг с целью удовлетворения общественных потребностей и получения прибыли.

**Фирма** — это более широкое понятие, охватывающее любую организационно-хозяйственную единицу, осуществляющую предпринимательскую деятельность.

---

## Цели предприятия в рыночной экономике

| Цель | Описание |
|------|----------|
| **Максимизация прибыли** | Основная цель в классической рыночной экономике |
| **Удовлетворение потребностей** | Производство товаров и услуг, востребованных рынком |
| **Обеспечение долгосрочной устойчивости** | Выживание и развитие в конкурентной среде |
| **Социальная ответственность** | Учёт интересов работников, общества, экологии |

---

## Признаки предприятия

| Признак | Описание |
|---------|----------|
| **Организационное единство** | Коллектив, структура, управление |
| **Производственно-техническое единство** | Взаимосвязь процессов, общая инфраструктура |
| **Экономическая обособленность** | Самостоятельность в распоряжении ресурсами |
| **Самоокупаемость** | Покрытие расходов за счёт доходов |
| **Самофинансирование** | Развитие за счёт собственных средств |
| **Юридическая самостоятельность** | Регистрация, устав, права и обязанности |

---

## Классификация предприятий

### По форме собственности

| Тип | Описание |
|-----|----------|
| **Государственные** | Принадлежат государству |
| **Муниципальные** | Принадлежат местным органам власти |
| **Частные** | Принадлежат частным лицам |
| **Смешанные** | Комбинированная собственность |

### По размеру

| Категория | Критерии (РФ) |
|-----------|---------------|
| **Микропредприятия** | До 15 сотрудников, доход до 120 млн руб. |
| **Малые** | 16–100 сотрудников, доход до 800 млн руб. |
| **Средние** | 101–250 сотрудников, доход до 2 млрд руб. |
| **Крупные** | Свыше 250 сотрудников, доход свыше 2 млрд руб. |

### По организационно-правовой форме (РФ)

| Форма | Особенности |
|-------|-------------|
| **ИП** | Индивидуальный предприниматель, полная ответственность |
| **ООО** | Общество с ограниченной ответственностью, уставный капитал |
| **АО** | Акционерное общество, акции (публичное / непубличное) |
| **ПАО** | Публичное акционерное общество, акции на рынке |
| **Производственный кооператив** | Объединение для совместной деятельности |
| **Унитарное предприятие** | Государственное или муниципальное, без права собственности |

### По отраслевой принадлежности

| Отрасль | Примеры |
|---------|---------|
| **Промышленность** | Машиностроение, металлургия, пищевая |
| **Сельское хозяйство** | Растениеводство, животноводство |
| **Строительство** | Жилищное, промышленное |
| **Транспорт** | Грузовые и пассажирские перевозки |
| **Торговля** | Оптовая, розничная |
| **Услуги** | Образование, медицина, IT |

## Предпринимательская деятельность

**Предпринимательство** — это самостоятельная, инициативная деятельность, направленная на систематическое получение прибыли и осуществляемая на свой риск.

### Функции предпринимательства

| Функция | Описание |
|---------|----------|
| **Ресурсная** | Объединение и использование ресурсов |
| **Инновационная** | Внедрение новшеств |
| **Рисковая** | Принятие на себя рисков |
| **Социальная** | Создание рабочих мест |

---

## Принципы деятельности предприятия в рыночной экономике

| Принцип | Содержание |
|---------|------------|
| **Самостоятельность** | Независимость в принятии решений |
| **Самоокупаемость** | Покрытие затрат доходами |
| **Рентабельность** | Получение прибыли |
| **Конкурентоспособность** | Способность конкурировать на рынке |
| **Адаптивность** | Гибкое реагирование на изменения |
| **Эффективность** | Оптимальное соотношение затрат и результатов |

---

## Вывод

Предприятие — это основное звено рыночной экономики. В условиях рынка предприятие самостоятельно определяет свою стратегию, планирует производство, ищет ресурсы и сбывает продукцию, неся полную ответственность за результаты своей деятельности. Успех предприятия зависит от его способности адаптироваться к изменениям внешней среды, эффективно использовать ресурсы и удовлетворять потребности клиентов с прибылью для себя.
