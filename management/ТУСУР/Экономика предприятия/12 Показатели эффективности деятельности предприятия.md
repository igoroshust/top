# 12 Показатели эффективности деятельности предприятия

## Определение

**Эффективность деятельности предприятия** — это соотношение между результатами (эффектом) и затратами (ресурсами), использованными для достижения этих результатов. Чем больше результат на единицу затрат, тем выше эффективность.

---

## Общая классификация показателей эффективности

```
ПОКАЗАТЕЛИ ЭФФЕКТИВНОСТИ
    │
    ├── Экономическая эффективность
    │   ├── Прибыль и рентабельность
    │   ├── Производительность
    │   └── Ресурсоотдача
    │
    ├── Финансовая эффективность
    │   ├── Ликвидность и платёжеспособность
    │   ├── Финансовая устойчивость
    │   └── Деловая активность
    │
    └── Социальная эффективность
        ├── Уровень зарплаты
        ├── Текучесть кадров
        └── Безопасность труда
```

---

## 1. Показатели экономической эффективности

### 1.1. Показатели прибыли

| Показатель | Формула | Краткая характеристика |
|------------|---------|----------------------|
| **Валовая прибыль** | Выручка — Себестоимость | Результат основной деятельности |
| **Прибыль от продаж** | Вал. прибыль — Коммерч. — Управл. | С учётом сбыта и управления |
| **Чистая прибыль** | Пдн — Налог на прибыль | Конечный результат |

### 1.2. Показатели рентабельности

| Показатель | Формула | Характеристика |
|------------|---------|----------------|
| **Рентабельность продаж (ROS)** | Прибыль от продаж / Выручка × 100% | Доля прибыли в выручке |
| **Рентабельность продукции** | Прибыль от продаж / Себестоимость × 100% | Доходность затрат |
| **Рентабельность активов (ROA)** | Чистая прибыль / Активы × 100% | Отдача на активы |
| **Рентабельность собственного капитала (ROE)** | Чистая прибыль / Собств. капитал × 100% | Доходность для собственников |
| **Рентабельность основных фондов** | Прибыль / ОПФср × 100% | Доходность фондов |
| **Рентабельность оборотных средств** | Прибыль / ОбСср × 100% | Доходность оборотных средств |
| **Рентабельность инвестиций (ROI)** | Прибыль / Инвестиции × 100% | Возврат на инвестиции |

### 1.3. Показатели ресурсоотдачи

| Показатель | Формула | Характеристика |
|------------|---------|----------------|
| **Фондоотдача** | ТП / ОСср | Выпуск на 1 руб. ОС |
| **Фондоёмкость** | ОСср / ТП | Затраты ОС на 1 руб. продукции |
| **Оборачиваемость оборотных средств** | РП / ОбСср | Количество оборотов |
| **Длительность оборота** | Дп / Коб | Длительность 1 оборота |
| **Производительность труда** | ТП / Чср | Выпуск на 1 работника |
| **Трудоёмкость** | Час / Q | Затраты времени на единицу |
| **Материалоотдача** | ТП / МЗ | Выпуск на 1 руб. материалов |
| **Материалоёмкость** | МЗ / ТП | Затраты материалов на 1 руб. продукции |

## 2. Показатели финансовой эффективности

### 2.1. Показатели ликвидности

| Показатель | Формула | Норматив |
|------------|---------|----------|
| **Коэффициент абсолютной ликвидности** | (ДС + КФВ) / КО | 0,2–0,5 |
| **Коэффициент быстрой ликвидности** | (ДС + КФВ + ДЗ) / КО | 0,7–1,0 |
| **Коэффициент текущей ликвидности** | ОА / КО | 1,5–2,5 |

Где: ДС — денежные средства, КФВ — краткосрочные вложения, ДЗ — дебиторская задолженность, КО — краткосрочные обязательства, ОА — оборотные активы.

### 2.2. Показатели финансовой устойчивости

| Показатель | Формула | Норматив |
|------------|---------|----------|
| **Коэффициент автономии** | СК / ВБ | > 0,5 |
| **Коэффициент финансовой зависимости** | ЗК / ВБ | < 0,5 |
| **Коэффициент обеспеченности собственными средствами** | (СК — ВА) / ОА | > 0,1 |
| **Коэффициент маневренности** | (СК — ВА) / СК | 0,2–0,5 |

Где: СК — собственный капитал, ЗК — заёмный капитал, ВБ — валюта баланса (активы), ВА — внеоборотные активы.

### 2.3. Показатели деловой активности (оборачиваемости)

| Показатель | Формула |
|------------|---------|
| **Оборачиваемость активов** | Выручка / Активы |
| **Оборачиваемость дебиторской задолженности** | Выручка / ДЗ ср |
| **Оборачиваемость кредиторской задолженности** | Себестоимость / КЗ ср |
| **Оборачиваемость запасов** | Себестоимость / Запасы ср |

## 3. Показатели социальной эффективности

| Показатель | Формула | Характеристика |
|------------|---------|----------------|
| **Средняя зарплата** | ФОТ / Чср | Уровень оплаты труда |
| **Темп роста зарплаты** | ЗПотч / ЗПбаз × 100% | Динамика |
| **Текучесть кадров** | Чувол / Чср × 100% | Стабильность коллектива |
| **Затраты на обучение** | Расходы на обучение / Чср | Развитие персонала |
| **Уровень травматизма** | Число травм / Чср × 1000 | Безопасность труда |

## Система сбалансированных показателей (Balanced Scorecard — BSC)

Концепция BSC (Каплан и Нортон, 1992) предлагает оценивать эффективность по четырём перспективам:

| Перспектива | Фокус | Показатели |
|-------------|-------|------------|
| **Финансы** | Как нас видят акционеры? | ROE, ROI, прибыль |
| **Клиенты** | Как нас видят клиенты? | NPS, доля рынка |
| **Процессы** | В чём мы должны быть эффективны? | Качество, сроки |
| **Развитие** | Как мы будем развиваться? | Обучение, инновации |

## Анализ эффективности (методика)

| Этап | Действия |
|------|----------|
| **1. Горизонтальный анализ** | Сравнение показателей в динамике |
| **2. Вертикальный анализ** | Структура показателей |
| **3. Факторный анализ** | Влияние факторов на результат |
| **4. Сравнительный анализ** | Сравнение с планом, конкурентами |
| **5. Выводы и рекомендации** | Пути улучшения |

---

## Вывод

Эффективность деятельности предприятия — многогранное понятие, оцениваемое через экономические (прибыль, рентабельность, ресурсоотдача), финансовые (ликвидность, устойчивость, оборачиваемость) и социальные (зарплата, текучесть, безопасность) показатели. Комплексный анализ по всем группам показателей позволяет оценить реальное состояние предприятия, выявить проблемы и определить направления для улучшения. Система сбалансированных показателей (BSC) обеспечивает интеграцию финансовых и нефинансовых аспектов эффективности.
