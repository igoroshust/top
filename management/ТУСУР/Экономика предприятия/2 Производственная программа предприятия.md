# 2 Производственная программа предприятия

## Определение

**Производственная программа** — это план производства и реализации продукции, который устанавливает объём, номенклатуру, ассортимент и качество продукции, подлежащей выпуску в плановом периоде.

Производственная программа является основой для расчёта потребности в ресурсах, загрузки оборудования, численности персонала, себестоимости и финансовых результатов.

---

## Цели разработки производственной программы

| Цель | Описание |
|------|----------|
| **Обеспечение спроса** | Производство продукции, востребованной рынком |
| **Максимизация прибыли** | Оптимальная загрузка мощностей |
| **Эффективное использование ресурсов** | Минимизация простоев и потерь |
| **Выполнение договорных обязательств** | Своевременные поставки |

---

## Показатели производственной программы

### Натуральные показатели

| Показатель | Единица измерения | Пример |
|------------|------------------|--------|
| **Объём производства** | Штуки, тонны, метры | 10 000 шт. |
| **Номенклатура** | Перечень наименований | Столы, стулья, шкафы |
| **Ассортимент** | Виды внутри номенклатуры | Столы письменные, кухонные |
| **Качество** | Сортность, соответствие стандартам | Высший сорт |

### Стоимостные показатели

| Показатель | Описание | Формула |
|------------|----------|---------|
| **Товарная продукция (ТП)** | Продукция, предназначенная для реализации | ТП = ∑(Цена i × Объём i) |
| **Валовая продукция (ВП)** | Вся продукция (включая незавершённое производство) | ВП = ТП + (НЗПк — НЗПн) |
| **Реализованная продукция (РП)** | Продукция, оплаченная покупателем | РП = ТП + (Он — Ок) |
| **Чистая продукция (ЧП)** | ТП минус материальные затраты | ЧП = ТП — МЗ |

**Где:**
- НЗПн, НЗПк — незавершённое производство на начало и конец периода;
- Он, Ок — остатки готовой продукции на складе на начало и конец периода;
- МЗ — материальные затраты.

## Этапы разработки производственной программы

| Этап | Действия |
|------|----------|
| **1. Анализ рынка и портфеля заказов** | Изучение спроса, заключение договоров |
| **2. Определение номенклатуры и ассортимента** | Выбор продукции для производства |
| **3. Расчёт объёмов производства** | В натуральном и стоимостном выражении |
| **4. Обоснование производственной мощностью** | Проверка возможности выпуска |
| **5. Расчёт потребности в ресурсах** | Сырьё, материалы, оборудование, персонал |
| **6. Составление графика выпуска** | Распределение по месяцам / кварталам |
| **7. Контроль выполнения** | Отслеживание отклонений |

## Производственная мощность

### Определение

**Производственная мощность** — это максимально возможный выпуск продукции в единицу времени при полном использовании производственного оборудования и площадей.

### Виды мощностей

| Вид | Описание |
|-----|----------|
| **Входная** | Мощность на начало периода |
| **Выходная** | Мощность на конец периода |
| **Проектная** | Мощность, заложенная в проекте |
| **Среднегодовая** | Средняя мощность за период |

### Расчёт производственной мощности

**Для непрерывного производства:**
```
М = (Тэф × Коб) / t
```
Где:
- М — мощность в натуральных единицах;
- Тэф — эффективный фонд времени работы оборудования;
- Коб — количество единиц оборудования;
- t — трудоёмкость единицы продукции.

### Коэффициент использования мощности

```
Кисп = ВПфакт / Мср × 100%
```

Где:
- Кисп — коэффициент использования мощности;
- ВПфакт — фактический объём выпуска;
- Мср — среднегодовая мощность.

## Показатели выполнения производственной программы

| Показатель | Формула | Что показывает |
|------------|---------|----------------|
| **Выполнение плана по объёму** | (Факт / План) × 100% | Процент выполнения |
| **Выполнение по номенклатуре** | (Факт номенклатуры / План) × 100% | Полнота выпуска |
| **Ритмичность** | (Выпуск по графику / Всего выпуск) × 100% | Равномерность выпуска |
| **Качество** | (Продукция высшего сорта / Вся продукция) × 100% | Доля качественной |

## Вывод

Производственная программа — это центральный раздел плана предприятия, определяющий объёмы, номенклатуру и ассортимент продукции. Она тесно связана с производственной мощностью, которая ограничивает максимально возможный выпуск. Разработка программы включает анализ рынка, расчёт мощностей, обоснование ресурсами и составление графика. Контроль выполнения программы осуществляется через показатели объёма, номенклатуры, ритмичности и качества.
