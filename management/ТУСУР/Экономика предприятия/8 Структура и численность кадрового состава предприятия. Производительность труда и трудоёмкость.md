# 8 Структура и численность кадрового состава предприятия. Производительность труда и трудоёмкость

## Определение

**Кадровый состав (персонал) предприятия** — это совокупность работников различных профессий, специальностей и квалификации, занятых на предприятии.

**Производительность труда** — это показатель эффективности трудовой деятельности, измеряемый количеством продукции, произведённой в единицу рабочего времени, или затратами времени на единицу продукции.

---

## Структура кадрового состава

### Категории персонала

| Категория | Состав | Функции |
|-----------|--------|---------|
| **Рабочие** | Основные и вспомогательные | Непосредственное производство продукции |
| **Специалисты** | Инженеры, технологи, экономисты | Разработка, проектирование, анализ |
| **Служащие** | Секретари, операторы, делопроизводители | Документооборот, администрирование |
| **Руководители** | Высшего, среднего, низового звена | Управление подразделениями |
| **Младший обслуживающий персонал** | Уборщики, курьеры | Обслуживание |

### Соотношение категорий (пример для промышленности)

| Категория | Доля в численности |
|-----------|-------------------|
| Рабочие | 70–80% |
| Специалисты | 10–15% |
| Служащие | 3–5% |
| Руководители | 5–7% |
| МОП | 1–2% |

---

## Показатели численности кадрового состава

### 1. Списочная численность
Все работники, принятые на постоянную, сезонную или временную работу на срок от 1 дня.

### 2. Явочная численность
Количество работников, явившихся на работу.

### 3. Среднесписочная численность
Средняя численность за период.

**Формула для месяца:**
```
Чср = (Чсп1 + Чсп2 + ... + Чспn) / N
```
Где:
- Чспn — списочная численность за каждый день;
- N — число календарных дней.

**Формула для года:**
```
Чсргод = (Чср1 + Чср2 + ... + Чср12) / 12
```

### 4. Коэффициент соотношения категорий

```
Ксоот = Численность категории / Общая численность
```

## Производительность труда

### Методы измерения

| Метод | Единица измерения | Суть | Применение |
|-------|-------------------|------|------------|
| **Натуральный** | Шт., т, м | Объём в натуральных единицах | Однородная продукция |
| **Стоимостной** | Рубли | Объём в денежном выражении | Разнородная продукция |
| **Трудовой** | Нормо-часы | Затраты времени на выпуск | Сложная продукция |

### Показатели

#### Выработка (прямой показатель)

```
В = Q / Ч
```
Где:
- Q — объём произведённой продукции (в натуральных, стоимостных или трудовых единицах);
- Ч — численность работников (или затраты времени).

**Показывает:** количество продукции на одного работника (или за единицу времени).

#### Трудоёмкость (обратный показатель)

```
Тр = Затраты времени / Q
```

**Показывает:** затраты времени на единицу продукции.

---

## Виды трудоёмкости

| Вид | Состав затрат |
|-----|---------------|
| **Технологическая** | Затраты труда основных рабочих |
| **Обслуживания** | Затраты вспомогательных рабочих |
| **Производственная** | Технологическая + обслуживания |
| **Управления** | Затраты руководителей, специалистов |
| **Полная** | Производственная + управления |

---

## Факторы роста производительности труда

| Группа факторов | Примеры |
|----------------|---------|
| **Материально-технические** | Новая техника, автоматизация, модернизация |
| **Организационные** | Совершенствование организации труда и производства |
| **Социально-экономические** | Мотивация, квалификация, условия труда |
| **Структурные** | Изменение доли отдельных видов продукции |

---

## Резервы роста производительности труда

| Резерв | Мероприятия |
|--------|-------------|
| **Снижение трудоёмкости** | Автоматизация, новые технологии |
| **Улучшение использования рабочего времени** | Сокращение простоев, прогулов |
| **Совершенствование организации труда** | Нормирование, кооперация |
| **Повышение квалификации** | Обучение, переподготовка |
| **Улучшение мотивации** | Материальное и нематериальное стимулирование |

### Расчёт резерва роста производительности

```
Рост ПТ = (Резерв снижения Тр) / (Базовая Тр — Резерв) × 100%
```

---

## Вывод

Кадровый состав — это совокупность работников разных категорий (рабочие, специалисты, служащие, руководители). Производительность труда — ключевой показатель эффективности использования трудовых ресурсов, измеряемый выработкой (прямой показатель) или трудоёмкостью (обратный). Рост производительности труда обеспечивается за счёт технических, организационных и социальных факторов. Резервы роста включают снижение трудоёмкости, улучшение использования времени и повышение квалификации.
