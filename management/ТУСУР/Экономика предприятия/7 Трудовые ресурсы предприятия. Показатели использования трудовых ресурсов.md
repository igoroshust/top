# 7 Трудовые ресурсы предприятия. Показатели использования трудовых ресурсов

## Определение

**Трудовые ресурсы предприятия** — это часть населения, которая по возрасту и состоянию здоровья способна к трудовой деятельности, а также занята или может быть занята в экономике.

В масштабах предприятия трудовые ресурсы — это численность и состав персонала, необходимого для выполнения производственных функций.

---

## Состав трудовых ресурсов

### Классификация по категориям

```
ПЕРСОНАЛ ПРЕДПРИЯТИЯ
    │
    ├── Промышленно-производственный персонал (ППП)
    │   ├── Рабочие (основные и вспомогательные)
    │   ├── Специалисты (инженеры, технологи, экономисты)
    │   ├── Служащие (операторы, секретари)
    │   └── Руководители (директора, начальники цехов, мастера)
    │
    └── Непромышленный персонал
        └── Работники ЖКХ, столовых, медсанчастей, детсадов
```

### Классификация по профессиям, специальностям, квалификации

| Признак | Описание | Примеры |
|---------|----------|---------|
| **Профессия** | Род трудовой деятельности | Токарь, экономист |
| **Специальность** | Вид деятельности в рамках профессии | Токарь-карусельщик, бухгалтер |
| **Квалификация** | Уровень подготовки (разряд, категория) | 1–6 разряд, I–III категория |

## Показатели численности персонала

### 1. Явочная численность
Количество работников, которые должны явиться на работу для выполнения производственного задания.

### 2. Списочная численность
Все работники, принятые на постоянную, сезонную или временную работу на срок 1 день и более.

### 3. Среднесписочная численность
Среднее число работников за период (месяц, квартал, год):

```
Чср = (Сумма списочных чисел за каждый день) / (Число календарных дней)
```

## Движение кадров

### Показатели движения

| Показатель | Формула | Что показывает |
|------------|---------|----------------|
| **Коэффициент оборота по приёму** | Кпр = Чприн / Чср | Доля принятых |
| **Коэффициент оборота по выбытию** | Квыб = Чувол / Чср | Доля уволенных |
| **Коэффициент текучести** | Ктек = (Чув.по собств. + Чув.за наруш.) / Чср | Интенсивность смены кадров |
| **Коэффициент постоянства** | Кпост = Чпрораб.весь год / Чср | Стабильность состава |

### Причины текучести кадров

| Причина | Описание |
|---------|----------|
| Низкая зарплата | Неудовлетворённость оплатой труда |
| Отсутствие карьерного роста | Нет перспектив |
| Плохие условия труда | Вредное производство, перегрузки |
| Конфликты в коллективе | Напряжённые отношения |
| Личные причины | Переезд, смена сферы деятельности |

## Показатели использования трудовых ресурсов

### 1. Использование рабочего времени

**Фонды времени:**

| Показатель | Формула |
|------------|---------|
| **Календарный фонд** | Число календарных дней × Чср |
| **Табельный фонд** | Календарный — праздничные и выходные |
| **Максимально возможный** | Табельный — очередные отпуска |
| **Явочный фонд** | Максимально возможный — неявки |
| **Фактически отработанное** | Явочный — целодневные простои |

**Коэффициенты использования времени:**

| Показатель | Формула |
|------------|---------|
| Коэффициент использования календарного фонда | Факт / Календарный |
| Коэффициент использования табельного фонда | Факт / Табельный |
| Коэффициент использования макс. возможного | Факт / Максимально возможный |

### 2. Средняя продолжительность рабочего дня

```
Тср = ∑(Часi) / Чотр
```

Где:
- Часi — отработанные часы;
- Чотр — отработанные человеко-дни.

## Вывод

Трудовые ресурсы — один из ключевых факторов производства. Эффективность использования трудовых ресурсов характеризуется показателями движения кадров (текучесть, оборачиваемость) и использования рабочего времени. Снижение текучести и потерь рабочего времени — важные резервы повышения эффективности предприятия.
