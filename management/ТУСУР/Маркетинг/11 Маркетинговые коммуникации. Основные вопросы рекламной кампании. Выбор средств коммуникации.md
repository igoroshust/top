# 11 Маркетинговые коммуникации. Основные вопросы рекламной кампании. Выбор средств коммуникации

## Определение

**Маркетинговые коммуникации** — это совокупность инструментов и методов, с помощью которых компания передаёт информацию о своих товарах, услугах и бренде целевым аудиториям с целью формирования спроса, стимулирования продаж и создания долгосрочных отношений.

---

## Комплекс маркетинговых коммуникаций (Promotion Mix)

```
МАРКЕТИНГОВЫЕ КОММУНИКАЦИИ
    │
    ├── Реклама (Advertising)
    ├── Стимулирование сбыта (Sales Promotion)
    ├── Связи с общественностью (PR)
    ├── Личные продажи (Personal Selling)
    ├── Прямой маркетинг (Direct Marketing)
    └── Цифровые коммуникации (Digital)
```

| Инструмент | Описание | Примеры |
|------------|----------|---------|
| **Реклама** | Платная, безличная форма продвижения | ТВ-ролики, баннеры, радио |
| **Стимулирование сбыта** | Краткосрочные стимулы для покупки | Скидки, акции, купоны |
| **PR** | Формирование положительного имиджа | Пресс-релизы, мероприятия |
| **Личные продажи** | Прямое взаимодействие продавца и покупателя | Презентации, консультации |
| **Прямой маркетинг** | Индивидуальная коммуникация | Email-рассылки, телемаркетинг |
| **Digital-коммуникации** | Продвижение через цифровые каналы | SMM, SEO, контент-маркетинг |

---

## Основные вопросы рекламной кампании (модель 5М)

При планировании рекламной кампании нужно ответить на 5 ключевых вопросов:

| Вопрос | Англ. | Содержание |
|--------|-------|------------|
| **Какова цель?** | Mission | Чего хотим достичь? |
| **Сколько средств?** | Money | Какой бюджет? |
| **Кто целевая аудитория?** | Market | Кого хотим охватить? |
| **Какое сообщение?** | Message | Что хотим сказать? |
| **Какие каналы?** | Media | Какие средства использовать? |

### 1. Mission (Цель рекламы)

| Цель | Описание | Пример |
|------|----------|--------|
| **Информирование** | Рассказ о новом продукте | Запуск нового смартфона |
| **Убеждение** | Стимулирование покупки | «Купи сейчас со скидкой» |
| **Напоминание** | Поддержание осведомлённости | Реклама Coca-Cola |
| **Создание имиджа** | Формирование образа бренда | Премиум-реклама |

### 2. Money (Бюджет)

| Метод определения бюджета | Описание |
|---------------------------|----------|
| **% от продаж** | Фиксированный процент от выручки |
| **Ориентация на конкурентов** | На уровне конкурентов |
| **Цели и задачи** | Исходя из задач кампании |
| **Остаточный** | Всё, что осталось после других расходов |

### 3. Market (Целевая аудитория)

- Кто наши клиенты (демография, психография);
- Где находится аудитория;
- Когда она наиболее восприимчива.

### 4. Message (Сообщение)

| Элемент сообщения | Описание |
|-------------------|----------|
| **Рациональное обращение** | Выгода, качество, экономия |
| **Эмоциональное обращение** | Страх, радость, гордость |
| **Моральное обращение** | Справедливость, ответственность |

**Формула AIDA:**
- Attention (внимание) — привлечь;
- Interest (интерес) — заинтересовать;
- Desire (желание) — вызвать желание;
- Action (действие) — побудить к покупке.

### 5. Media (Выбор средств коммуникации)

#### Классификация каналов

| Канал | Охват | Стоимость | Таргетинг | Примеры |
|-------|-------|-----------|-----------|---------|
| **ТВ** | Массовый | Высокая | Низкий | Рекламные ролики |
| **Радио** | Массовый | Средняя | Низкий | Аудиоролики |
| **Пресса** | Целевой | Средняя | Средний | Газеты, журналы |
| **Наружная реклама** | Массовый | Средняя | Низкий | Билборды, ситилайты |
| **Интернет** | Целевой | Низкая-средняя | Высокий | Таргетинг, SEO, SMM |
| **Социальные сети** | Целевой | Низкая | Высокий | Instagram, VK, Telegram |

## Выбор средств коммуникации

### Критерии выбора

| Критерий | Вопрос |
|----------|--------|
| **Охват** | Сколько людей мы хотим охватить? |
| **Частота** | Сколько раз должен увидеть человек? |
| **Влияние** | Насколько канал воздействует? |
| **Таргетинг** | Насколько точно можно попасть в ЦА? |
| **Стоимость** | Какой бюджет? |
| **Сроки** | Как быстро нужно запустить? |

### Охват, частота, влияние

| Параметр | Описание |
|----------|----------|
| **Охват** | Количество человек, увидевших рекламу |
| **Частота** | Сколько раз каждый увидел рекламу |
| **Влияние** | Сила воздействия канала на аудиторию |

### Матрица соответствия каналов и целей

| Цель | Рекомендуемые каналы |
|------|---------------------|
| Массовое информирование | ТВ, наружная реклама |
| Быстрые продажи | Стимулирование сбыта, email |
| Имидж и престиж | PR, ТВ, пресса |
| Точный таргетинг | Digital, социальные сети |
| Сложный продукт (B2B) | Личные продажи, контент-маркетинг |

## Медиапланирование

**Медиаплан** — это документ, описывающий, когда, где, с какой частотой и с каким бюджетом будут размещаться рекламные сообщения.

| Этап | Действия |
|------|----------|
| 1. Анализ аудитории | Изучение медиапотребления ЦА |
| 2. Определение целей | Охват, частота, GRP |
| 3. Выбор каналов | ТВ, радио, интернет и т.д. |
| 4. Разработка графика | Расписание размещений |
| 5. Распределение бюджета | По каналам и периодам |
| 6. Оценка эффективности | Анализ достижения KPI |

### Показатели эффективности медиаплана

| Показатель | Описание |
|------------|----------|
| **GRP** | Суммарный рейтинг всех размещений |
| **CPT** | Стоимость за 1000 контактов |
| **CPC** | Стоимость за 1 клик |
| **CPA** | Стоимость за 1 действие (покупку) |
| **ROI** | Возврат на инвестиции |

## Вывод

Маркетинговые коммуникации — это комплекс инструментов, позволяющих компании эффективно взаимодействовать с целевой аудиторией. Планирование рекламной кампании начинается с ответов на пять ключевых вопросов (5М): цель, бюджет, аудитория, сообщение, каналы. Выбор средств коммуникации зависит от целей кампании, характеристики аудитории и бюджета. Грамотное медиапланирование обеспечивает максимальную эффективность при заданных ограничениях.
