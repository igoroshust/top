# 8 Товар в маркетинге. Жизненный цикл товара. Портфель товаров и услуг (матрица Бостонской консультативной группы). Разработка нового товара

## Определение товара в маркетинге

**Товар** — это всё, что может удовлетворить потребность и предлагается рынку для приобретения, использования или потребления.

---

## Три уровня товара (Ф. Котлер)

```
            ┌──────────────────────────┐
            │   Товар с подкреплением  │
            │  (гарантия, сервис,      │
            │   доставка, монтаж)      │
            │   ┌─────────────────┐    │
            │   │ Товар в реальном│    │
            │   │ исполнении      │    │
            │   │ (качество,      │    │
            │   │  дизайн, бренд, │    │
            │   │  упаковка)      │    │
            │   │  ┌──────────┐   │    │
            │   │  │ Товар по │   │    │
            │   │  │ замыслу  │   │    │
            │   │  │(основная │   │    │
            │   │  │ выгода)  │   │    │
            │   │  └──────────┘   │    │
            │   └─────────────────┘    │
            └──────────────────────────┘
```

| Уровень | Описание | Пример (смартфон) |
|---------|----------|-------------------|
| **Товар по замыслу** | Основная выгода/услуга | Связь, доступ в интернет |
| **Товар в реальном исполнении** | Конкретные характеристики | Дизайн, бренд, ОС, камера |
| **Товар с подкреплением** | Дополнительные услуги | Гарантия, сервис, аксессуары |

## Жизненный цикл товара (ЖЦТ)

**Жизненный цикл товара** — это последовательность этапов, через которые проходит продукт на рынке: от появления до ухода.

### Классические стадии ЖЦТ

```
     Объём продаж
         │
         │          ┌──────────┐
         │         /│          │\
         │        / │          │ \
         │       /  │          │  \
         │      /   │          │   \
         │   ┌─┘    │          │    └───
         │  /│      │          │
         │ / │      │          │
         │/  │      │          │
         └───┴──────┴──────────┴───────── Время
         Внедрение   Рост    Зрелость   Спад
```

#### 1. Внедрение (вывод на рынок)
| Характеристика | Описание |
|----------------|----------|
| **Продажи** | Низкие, медленный рост |
| **Прибыль** | Отрицательная (инвестиции) |
| **Конкуренция** | Минимальная |
| **Маркетинг** | Информирование, создание спроса |
| **Цена** | Высокая (снятие сливок) или низкая (проникновение) |

#### 2. Рост
| Характеристика | Описание |
|----------------|----------|
| **Продажи** | Быстрый рост |
| **Прибыль** | Рост, выход на самоокупаемость |
| **Конкуренция** | Появление новых игроков |
| **Маркетинг** | Расширение рынка, дифференциация |

#### 3. Зрелость
| Характеристика | Описание |
|----------------|----------|
| **Продажи** | Стабильные, пик |
| **Прибыль** | Максимальная, стабильная |
| **Конкуренция** | Интенсивная |
| **Маркетинг** | Удержание доли, модификации, скидки |

#### 4. Спад
| Характеристика | Описание |
|----------------|----------|
| **Продажи** | Снижение |
| **Прибыль** | Падение |
| **Конкуренция** | Уход части игроков |
| **Маркетинг** | Минимизация затрат, снятие с производства |

### Стратегии на разных стадиях

| Стадия | Продукт | Цена | Продвижение | Сбыт |
|--------|---------|------|-------------|------|
| Внедрение | Базовая модель | Высокая/низкая | Информирование | Ограниченный |
| Рост | Расширение ассортимента | Снижение | Стимулирование | Расширение |
| Зрелость | Модификации | Конкурентная | Удержание | Максимальный |
| Спад | Упрощение | Снижение | Минимизация | Сокращение |

## Портфель товаров и услуг. Матрица BCG

**Матрица Бостонской консультативной группы (BCG)** — это инструмент анализа продуктового портфеля компании на основе двух параметров: темп роста рынка и относительная доля рынка.

```
        ВЫСОКАЯ          │       НИЗКАЯ
         доля рынка     │       доля рынка
────────────────────────┼────────────────────
ВЫСОКИЙ │                │
темп    │   «Звёзды»     │   «Трудные дети»
роста   │(Stars)         │(Question Marks)
рынка   │                │
        │  Прибыль: +++  │  Прибыль: +/-
        │  Деньги: ---  │  Деньги: ---
────────────────────────┼────────────────────
НИЗКИЙ │                │
темп    │  «Дойные       │   «Собаки»
роста   │   коровы»      │   (Dogs)
рынка   │  (Cash Cows)   │
        │                │
        │  Прибыль: +    │  Прибыль: -/+
        │  Деньги: +++   │  Деньги: --
```

### Характеристика квадрантов

| Квадрант | Характеристика | Стратегия |
|----------|----------------|-----------|
| **Звёзды** | Высокий рост, высокая доля. Требуют инвестиций | Инвестировать в рост |
| **Дойные коровы** | Низкий рост, высокая доля. Генерируют прибыль | Собирать прибыль, минимум инвестиций |
| **Трудные дети** | Высокий рост, низкая доля. Неопределённость | Анализировать: инвестировать или уйти |
| **Собаки** | Низкий рост, низкая доля. Нерентабельны | Уходить с рынка |

## Разработка нового товара

### Этапы разработки нового товара

| Этап | Действия |
|------|----------|
| **1. Генерация идей** | Мозговой штурм, анализ потребностей, конкуренты |
| **2. Отбор идей** | Оценка по критериям (стратегия, ресурсы, прибыльность) |
| **3. Разработка концепции** | Описание продукта, ЦА, преимущества |
| **4. Экономический анализ** | Прогноз продаж, затрат, прибыли, ROI |
| **5. Разработка продукта** | Создание прототипа, НИОКР |
| **6. Тестирование** | Лабораторные тесты, фокус-группы, пробный маркетинг |
| **7. Коммерциализация** | Запуск в производство, вывод на рынок |

### Причины неудач новых товаров

| Причина | Описание |
|---------|----------|
| **Слабая идея** | Продукт не решает реальной проблемы |
| **Недостаток исследований** | Не изучены потребности |
| **Плохой маркетинг** | Неправильное позиционирование |
| **Завышенная цена** | Несоответствие ценности |
| **Конкуренты** | Более сильный ответ конкурентов |
| **Технические проблемы** | Брак, низкое качество |

## Вывод

Товар — это центральное звено маркетинга-микс. Понимание жизненного цикла товара позволяет выбирать правильные стратегии на каждом этапе. Матрица BCG помогает управлять продуктовым портфелем, распределяя ресурсы между «звёздами», «дойными коровами», «трудными детьми» и «собаками». Разработка нового товара — это структурированный процесс от идеи до коммерциализации, где каждый этап снижает риски провала.
