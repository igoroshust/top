# 12 Рекламное объявление. Действие рекламы на аудиторию. Эмоциональное содержание и обещание выгоды. Использование стереотипов. Виды рекламной продукции. Связи с общественностью

## Определение

**Рекламное объявление** — это платное, однонаправленное, неличное сообщение, размещаемое в средствах массовой информации с целью информирования, убеждения или напоминания целевой аудитории о продукте, услуге или бренде.

---

## Структура рекламного объявления

| Элемент | Описание | Пример |
|---------|----------|--------|
| **Заголовок** | Привлекает внимание, содержит ключевое обещание | «Похудей на 10 кг за месяц!» |
| **Подзаголовок** | Развивает заголовок | «Без диет и спорта» |
| **Основной текст** | Аргументы, преимущества, призыв | Описание продукта |
| **Иллюстрация** | Визуальный элемент | Фото, рисунок |
| **Логотип / бренд** | Идентификация | Название компании |
| **Призыв к действию (CTA)** | Что сделать | «Купи сейчас!», «Закажи!» |

---

## Действие рекламы на аудиторию

### Модели воздействия рекламы

| Модель | Расшифровка | Этапы |
|--------|-------------|-------|
| **AIDA** | Attention-Interest-Desire-Action | Внимание → Интерес → Желание → Действие |
| **DAGMAR** | Defining Advertising Goals for Measured Advertising Results | Осведомлённость → Понимание → Убеждение → Действие |
| **Hierarchy of Effects** | Иерархия эффектов | Осведомлённость → Знание → Оценка → Предпочтение → Покупка |

### Психологические механизмы воздействия

| Механизм | Описание |
|----------|----------|
| **Привлечение внимания** | Яркие цвета, необычные образы, неожиданные решения |
| **Запоминание** | Повторы, слоганы, музыка, яркие образы |
| **Убеждение** | Аргументы, факты, отзывы, гарантии |
| **Эмоции** | Положительные (радость, гордость) и отрицательные (страх, тревога) |
| **Внушение** | Повторяющиеся утверждения, авторитет |

## Эмоциональное содержание и обещание выгоды

### Рациональные и эмоциональные обращение

| Тип обращения | Описание | Пример |
|---------------|----------|--------|
| **Рациональное** | Акцент на практических выгодах | «Стиральный порошок удаляет 99% пятен» |
| **Эмоциональное** | Акцент на чувствах | «Подарите близким тепло и заботу» |
| **Моральное** | Акцент на этике, ответственности | «Выбирая нашу упаковку, вы спасаете планету» |

### Базовые эмоции в рекламе

| Эмоция | Цель | Пример |
|--------|------|--------|
| **Радость** | Позитивная ассоциация | Семья, счастье, праздник |
| **Гордость** | Самоутверждение | «Вы этого достойны» |
| **Страх** | Побуждение к действию | «Не рискуйте здоровьем» |
| **Доверие** | Надёжность | «Рекомендовано врачами» |
| **Ностальгия** | Тёплые воспоминания | «Как в детстве» |

### Обещание выгоды (Unique Selling Proposition — USP)

**USP** — это уникальное торговое предложение, которое отличает продукт от конкурентов.

| Принципы USP | Описание |
|-------------|----------|
| **Конкретная выгода** | «Снижает холестерин на 20%» |
| **Уникальность** | «Единственный продукт с технологией X» |
| **Значимость** | «Экономит 50% электроэнергии» |

## Использование стереотипов в рекламе

**Стереотип** — это упрощённое, обобщённое представление о группе людей или ситуации.

### Типы стереотипов в рекламе

| Тип стереотипа | Пример |
|----------------|--------|
| **Гендерные** | Женщина — домохозяйка, мужчина — бизнесмен |
| **Возрастные** | Пожилые — консервативны, молодёжь — активна |
| **Социальные** | Богатые — в автомобилях, студенты — без денег |
| **Национальные** | Немцы — пунктуальны, итальянцы — эмоциональны |
| **Профессиональные** | Врач — в белом халате, IT-специалист — в очках |

### Почему используются стереотипы
- Быстрое узнавание и понимание;
- Экономия времени на обработку информации;
- Простота и доступность.

### Риски использования стереотипов
- Восприятие как оскорбительных или устаревших;
- Отторжение у современной аудитории;
- Репутационные риски.

## Виды рекламной продукции

### По месту размещения

| Вид | Описание | Пример |
|-----|----------|--------|
| **Печатная** | Бумажные носители | Буклеты, листовки, каталоги |
| **Наружная** | Уличные конструкции | Билборды, ситилайты, вывески |
| **Транзитная** | На транспорте | Реклама в метро, на автобусах |
| **ТВ-реклама** | Телевизионные ролики | Ролики 15–30 сек |
| **Радиореклама** | Аудиоформат | Аудиоспоты |
| **Интернет-реклама** | Онлайн-форматы | Баннеры, таргетинг, нативная |
| **POS-материалы** | В местах продаж | Шелфтокеры, гирлянды, стойки |
| **Сувенирная** | Подарки с брендом | Ручки, кружки, блокноты |

### По формату в интернете

| Формат | Описание |
|--------|----------|
| **Медийная (баннерная)** | Графические объявления |
| **Контекстная** | Объявления по поисковым запросам |
| **Таргетированная** | Реклама в соцсетях по интересам |
| **Нативная** | Естественно вписанная в контент |
| **Видеореклама** | Ролики на YouTube и других платформах |

## Связи с общественностью (PR)

**PR (Public Relations)** — это управленческая деятельность по формированию благоприятного общественного мнения о компании, её продуктах и услугах.

### Отличие PR от рекламы

| Критерий | Реклама | PR |
|----------|---------|-----|
| **Цель** | Продажа | Имидж, доверие |
| **Оплата** | Платная | Бесплатное упоминание (earned media) |
| **Контроль** | Полный контроль сообщения | Ограниченный контроль |
| **Доверие** | Низкое | Высокое |

### Инструменты PR

| Инструмент | Описание |
|------------|----------|
| **Пресс-релизы** | Новости для СМИ |
| **Пресс-конференции** | Мероприятия для журналистов |
| **Спонсорство** | Поддержка событий, организаций |
| **Мероприятия** | Конференции, выставки, форумы |
| **Интервью** | Выступления руководителей |
| **Кризисный PR** | Коммуникация в кризисных ситуациях |
| **Corporate Social Responsibility** | Социальная ответственность |

---

## Вывод

Реклама — это мощный инструмент маркетинговых коммуникаций, который воздействует на аудиторию через рациональные и эмоциональные обращения. Эффективное рекламное объявление содержит привлекающий заголовок, чёткое обещание выгоды, эмоциональную окраску и понятный призыв к действию. Стереотипы используются для упрощения восприятия, но требуют осторожности. PR формирует доверие и долгосрочную репутацию, дополняя рекламные усилия компании.
