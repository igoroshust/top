# 7 Система маркетинговой информации. Сбор данных. Источники вторичных данных. Качественные и количественные методы получения первичных данных. Подготовка аналитического отчета о состоянии рынка

## Определение

**Система маркетинговой информации (СМИ)** — это совокупность методов, процедур и ресурсов, используемых для сбора, обработки, хранения, анализа и распространения информации, необходимой для принятия маркетинговых решений.

---

## Структура системы маркетинговой информации

```
СИСТЕМА МАРКЕТИНГОВОЙ ИНФОРМАЦИИ
    │
    ├── Подсистема внутренней отчётности
    ├── Подсистема внешней маркетинговой информации (разведки)
    ├── Подсистема маркетинговых исследований
    └── Подсистема анализа и поддержки решений
```

### 1. Подсистема внутренней отчётности
- Данные о продажах;
- Финансовая отчётность;
- Данные о запасах и логистике;
- CRM-данные (история покупок, обращения);
- Отчёты отдела продаж.

### 2. Подсистема внешней маркетинговой информации (разведки)
- Мониторинг конкурентов;
- Отслеживание рыночных тенденций;
- Анализ публикаций в СМИ и соцсетях;
- Информация с выставок и конференций.

### 3. Подсистема маркетинговых исследований
- Специализированные проекты (опросы, фокус-группы);
- Сбор данных по конкретной проблеме.

### 4. Подсистема анализа и поддержки решений
- Статистические пакеты (SPSS, Python, R);
- BI-системы (Power BI, Tableau);
- Инструменты прогнозирования.

---

## Источники вторичных данных

**Вторичные данные** — это информация, собранная ранее для других целей, но пригодная для решения текущей задачи.

### Внутренние источники

| Источник | Примеры |
|----------|---------|
| **Финансовая отчётность** | Бухгалтерский баланс, отчёт о прибылях |
| **Данные о продажах** | Объёмы, динамика, ABC-анализ |
| **CRM** | История покупок, обращения, жалобы |
| **Маркетинговые отчёты** | Предыдущие исследования |
| **Данные о производстве** | Себестоимость, мощности |

### Внешние источники

| Тип | Источники |
|-----|-----------|
| **Государственная статистика** | Росстат, ФТС, ЦБ, Минэкономразвития |
| **Отраслевые отчёты** | РБК, Deloitte, PwC, Nielsen |
| **СМИ и соцсети** | Медиа-мониторинг, Brand Analytics |
| **Базы данных** | СПАРК, КонтурФокус (данные о компаниях) |
| **Исследования конкурентов** | Открытые отчёты, сайты, презентации |
| **Международные источники** | World Bank, IMF, OECD, Eurostat |

### Преимущества и недостатки вторичных данных

| Преимущества | Недостатки |
|-------------|------------|
| Быстрый сбор | Может быть устаревшей |
| Низкая стоимость | Неполное соответствие целям |
| Широкий охват | Непроверенное качество |
| Доступность | Обобщённость |

## Качественные методы получения первичных данных

**Первичные данные** — это информация, собранная специально для конкретного исследования.

| Метод | Описание | Размер выборки | Пример |
|-------|----------|----------------|--------|
| **Глубинные интервью** | Индивидуальные беседы 1 на 1 | 10–30 человек | Изучение мотивов покупки |
| **Фокус-группы** | Групповые дискуссии (6–12 человек) | 2–8 групп | Тестирование концепции |
| **Наблюдение** | Изучение поведения в естественной среде | — | Поведение в магазине |
| **Этнография** | Погружение в среду потребителей | — | Изучение использования продукта |
| **Дневники** | Ведение записей потребителями | 20–50 человек | Фиксация покупок |

**Цель качественных методов** — понять «почему?», выявить глубинные мотивы, гипотезы.

---

## Количественные методы получения первичных данных

| Метод | Описание | Размер выборки | Инструменты |
|-------|----------|----------------|-------------|
| **Опросы онлайн** | Анкетирование через интернет | 100–10000+ | Google Forms, Testograf, Яндекс.Взгляд |
| **Телефонные опросы** | CATI (компьютерный телефонный опрос) | 100–1000+ | Специализированное ПО |
| **Личные интервью** | Face-to-face опросы | 100–500 | Планшеты, бумажные анкеты |
| **A/B-тесты** | Сравнение двух версий | — | Optimizely, Google Optimize |
| **Панельные исследования** | Регулярный опрос одной группы | 500–5000+ | GfK, Ipsos, Nielsen |

**Цель количественных методов** — измерить «сколько?», получить статистически значимые данные.

## Подготовка аналитического отчёта о состоянии рынка

### Структура отчёта

| Раздел | Содержание |
|--------|------------|
| **1. Титульный лист** | Название, компания, дата, авторы |
| **2. Исполнительное резюме** | Ключевые выводы и рекомендации (1–2 стр.) |
| **3. Введение** | Цели, задачи, методология |
| **4. Обзор рынка** | Размер, динамика, структура, тренды |
| **5. PEST-анализ** | Политические, экономические, социальные, технологические факторы |
| **6. Конкурентный анализ** | Игроки, доли, стратегии, позиционирование |
| **7. Целевая аудитория** | Сегменты, портрет потребителя |
| **8. SWOT-анализ** | Сильные/слабые стороны, возможности/угрозы |
| **9. Выводы и рекомендации** | Практические рекомендации на основе данных |
| **10. Приложения** | Таблицы, графики, анкеты |

### Критерии качественного отчёта

| Критерий | Описание |
|----------|----------|
| **Полнота** | Все необходимые данные присутствуют |
| **Точность** | Данные корректны, указаны источники |
| **Ясность** | Понятный язык, минимум жаргона |
| **Визуализация** | Графики, таблицы, диаграммы |
| **Обоснованность** | Выводы основаны на данных |
| **Актуальность** | Данные не старше 1–2 лет |

### Инструменты для подготовки отчётов

| Инструмент | Назначение |
|------------|------------|
| Excel / Google Sheets | Сводные таблицы, расчёты |
| PowerPoint / Google Slides | Презентация |
| Power BI / Tableau | Визуализация и дашборды |
| Word / Google Docs | Текстовый отчёт |
| SPSS / Python / R | Статистический анализ |

## Вывод

Система маркетинговой информации — это основа для принятия обоснованных управленческих решений. Она включает внутренние и внешние источники, качественные и количественные методы сбора данных. Грамотно подготовленный аналитический отчёт позволяет менеджменту видеть полную картину рынка, выявлять возможности и угрозы, принимать стратегически верные решения.
