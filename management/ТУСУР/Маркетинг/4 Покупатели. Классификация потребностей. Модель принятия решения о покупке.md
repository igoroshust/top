# 4 Покупатели. Классификация потребностей. Модель принятия решения о покупке

## Определение

**Покупатель** — это лицо или организация, приобретающие товары или услуги для личного использования, перепродажи или производственных нужд.

**Потребитель** — это конечный пользователь товара или услуги (не всегда совпадает с покупателем).

---

## Типы покупателей

| Тип | Характеристика | Пример |
|-----|----------------|--------|
| **Индивидуальные (B2C)** | Покупают для личного потребления | Человек, покупающий продукты |
| **Корпоративные (B2B)** | Покупают для бизнес-нужд | Компания, закупающая ПО |
| **Государственные (B2G)** | Покупают для госнужд | Госучреждение, закупающее мебель |
| **Посредники** | Покупают для перепродажи | Розничный магазин |

## Классификация потребностей

### Иерархия потребностей по А. Маслоу

```
             ┌────────────────────┐
             │ Самоактуализация   │ — творчество, развитие
             ├────────────────────┤
             │    Уважение        │ — статус, признание, достижения
             ├────────────────────┤
             │   Социальные       │ — дружба, любовь, принадлежность
             ├────────────────────┤
             │  Безопасность      │ — стабильность, защита, здоровье
             ├────────────────────┤
             │ Физиологические    │ — еда, вода, сон, жильё
             └────────────────────┘
```

### Другие классификации потребностей

| Классификация | Виды потребностей |
|---------------|-------------------|
| **По происхождению** | Врождённые, приобретённые |
| **По характеру** | Материальные, духовные, социальные |
| **По субъекту** | Индивидуальные, групповые, общественные |
| **По степени осознания** | Осознанные, неосознанные |
| **По срочности удовлетворения** | Первичные (жизненно важные), вторичные |

### Потребности в маркетинговом контексте

| Потребность | Пример товара |
|-------------|---------------|
| **Функциональная** | «Хочу пить» — вода, сок |
| **Социальная** | «Хочу быть частью группы» — iPhone, брендовая одежда |
| **Эмоциональная** | «Хочу чувствовать себя в безопасности» — страхование |
| **Эгоистическая** | «Хочу выделиться» — люксовые товары |
| **Познавательная** | «Хочу узнать новое» — книги, курсы |

## Модель принятия решения о покупке

Классическая модель включает 5 этапов:

```
Осознание ──> Поиск ──> Оценка ──> Решение о ──> Поведение
проблемы      информации  альтернатив     покупке      после покупки
```

### Этап 1: Осознание проблемы

Покупатель осознаёт разницу между текущим и желаемым состоянием.

**Факторы, запускающие осознание:**
- Внутренние: голод, жажда, усталость;
- Внешние: реклама, рекомендации, пример других.

### Этап 2: Поиск информации

| Тип поиска | Источники |
|------------|-----------|
| **Внутренний** | Память, личный опыт |
| **Внешний** | Реклама, интернет, друзья, продавцы |

**Источники информации:**
- Личные (семья, друзья, знакомые);
- Коммерческие (реклама, сайты, продавцы);
- Публичные (СМИ, блоги, обзоры);
- Эмпирические (опыт использования, пробники).

### Этап 3: Оценка альтернатив

Покупатель сравнивает варианты по критериям:

| Критерий | Описание |
|----------|----------|
| **Цена** | Соответствие бюджету |
| **Качество** | Надёжность, характеристики |
| **Бренд** | Репутация, доверие |
| **Сервис** | Гарантия, поддержка |
| **Отзывы** | Мнение других покупателей |
| **Доступность** | Близость магазина, сроки доставки |

### Этап 4: Решение о покупке

Факторы, влияющие на окончательное решение:
- Отношение других людей (семья, коллеги);
- Ситуационные факторы (скидки, акции, наличие);
- Воспринимаемый риск (финансовый, социальный, функциональный).

### Этап 5: Поведение после покупки

| Тип реакции | Описание |
|-------------|----------|
| **Удовлетворение** | Ожидания совпали с реальностью — повторная покупка |
| **Восторг** | Реальность превзошла ожидания — лояльность, рекомендации |
| **Неудовлетворение** | Ожидания не оправдались — возврат, негативные отзывы |

---

## Факторы, влияющие на покупательское поведение

### Культурные факторы
- Культура и субкультура;
- Социальный класс.

### Социальные факторы
- Референтные группы (семья, друзья, коллеги);
- Социальные роли и статус.

### Личностные факторы
- Возраст и этап жизненного цикла;
- Доход;
- Образ жизни;
- Тип личности.

### Психологические факторы
- Мотивация;
- Восприятие (избирательное внимание, искажение, запоминание);
- Убеждения и установки;
- Обучение (опыт).

---

## Особенности принятия решений в B2B

| Характеристика | B2C | B2B |
|----------------|-----|-----|
| **Количество покупателей** | Много | Мало |
| **Стоимость покупки** | Низкая-средняя | Высокая |
| **Рациональность** | Эмоциональная | Рациональная |
| **Сложность решения** | Простая | Сложная, много участников |
| **Отношения** | Транзакционные | Долгосрочные |

---

## Вывод

Понимание потребностей и процесса принятия решения о покупке — основа маркетинга. Модель «Осознание — Поиск — Оценка — Решение — Поведение после покупки» позволяет маркетологу воздействовать на каждом этапе, помогая покупателю сделать выбор в пользу своего продукта.
