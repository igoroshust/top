# 2 Внешняя среда маркетинга. Социальные, технологические, экономические, политические факторы внешней среды. Конкурентное окружение

## Определение

**Внешняя среда маркетинга** — это совокупность факторов и сил, внешних по отношению к организации, которые влияют на её маркетинговую деятельность и возможности успешного взаимодействия с целевыми рынками. Организация не может контролировать эти факторы, но обязана их учитывать и адаптироваться к ним.

---

## Структура внешней среды маркетинга

```
ВНЕШНЯЯ СРЕДА
    │
    ├── МАКРОСРЕДА (PESTEL-факторы)
    │   ├── Политические (Political)
    │   ├── Экономические (Economic)
    │   ├── Социальные (Social)
    │   ├── Технологические (Technological)
    │   ├── Экологические (Environmental)
    │   └── Правовые (Legal)
    │
    └── МИКРОСРЕДА (конкурентное окружение)
        ├── Конкуренты
        ├── Поставщики
        ├── Посредники
        ├── Потребители
        └── Контактные аудитории
```

## Макросреда: PESTEL-факторы

### 1. Политические факторы (Political)

| Фактор | Влияние на маркетинг |
|--------|---------------------|
| Государственная политика и стабильность | Уверенность в долгосрочном планировании |
| Налоговая политика | Ценообразование, рентабельность |
| Регулирование рекламы | Ограничения на продвижение |
| Торговая политика (тарифы, квоты) | Международная торговля, цены |
| Поддержка предпринимательства | Стимулирование бизнеса |
| Антимонопольное регулирование | Конкурентная среда |

### 2. Экономические факторы (Economic)

| Фактор | Влияние на маркетинг |
|--------|---------------------|
| Инфляция | Ценообразование, покупательная способность |
| Уровень доходов населения | Платёжеспособный спрос |
| Безработица | Размер рынка, покупательская активность |
| Процентные ставки | Инвестиции, кредитование |
| Курс валют | Импорт/экспорт, цены на сырьё |
| ВВП и экономический рост | Общее состояние рынка |

### 3. Социальные факторы (Social)

| Фактор | Влияние на маркетинг |
|--------|---------------------|
| Демография (возраст, пол, численность) | Сегментация, размер рынка |
| Образ жизни и ценности | Потребности, предпочтения |
| Культурные нормы и традиции | Поведение потребителей |
| Мода и тренды | Спрос на определённые товары |
| Уровень образования | Восприятие рекламы, сложность продуктов |
| Социальная ответственность | Спрос на экологичные товары |

### 4. Технологические факторы (Technological)

| Фактор | Влияние на маркетинг |
|--------|---------------------|
| Новые технологии производства | Снижение издержек, качество |
| Цифровизация | Каналы коммуникации, e-commerce |
| Интернет и социальные сети | Продвижение, обратная связь |
| Big Data и аналитика | Персонализация, таргетинг |
| Искусственный интеллект | Автоматизация маркетинга |
| Мобильные технологии | Мобильная реклама, приложения |

### 5. Экологические факторы (Environmental)

| Фактор | Влияние на маркетинг |
|--------|---------------------|
| Климат и погода | Сезонность, специфика продуктов |
| Экологические нормы | Требования к продукции, упаковке |
| Доступность природных ресурсов | Сырьё, издержки |
| Отношение к экологии | Спрос на «зелёные» продукты |

### 6. Правовые факторы (Legal)

| Фактор | Влияние на маркетинг |
|--------|---------------------|
| Законы о защите прав потребителей | Гарантии, возврат, качество |
| Рекламное законодательство | Ограничения на рекламу |
| Патентное право | Защита инноваций |
| Трудовое законодательство | Персонал, издержки |

## Характеристики внешней среды

| Характеристика | Описание |
|----------------|----------|
| **Неопределённость** | Недостаток информации о факторах среды |
| **Сложность** | Множество факторов, влияющих на организацию |
| **Подвижность** | Скорость изменений во внешней среде |
| **Взаимосвязанность** | Изменение одного фактора влияет на другие |

## Конкурентное окружение (микросреда)

### 1. Конкуренты

**Типы конкуренции:**

| Тип | Описание | Пример |
|-----|----------|--------|
| **Прямая** | Аналогичные товары, схожий рынок | Coca-Cola vs Pepsi |
| **Косвенная** | Разные товары, удовлетворяющие одну потребность | Кино vs театр |
| **Потенциальная** | Новые игроки, входящие на рынок | Стартапы |
| **Товарная** | Схожие товары разных марок | Бренды стирального порошка |

**Пять сил конкуренции (М. Портер):**

1. Соперничество между существующими конкурентами;
2. Угроза появления новых конкурентов;
3. Угроза товаров-заменителей;
4. Рыночная власть поставщиков;
5. Рыночная власть покупателей.

### 2. Поставщики
Обеспечивают компанию ресурсами (сырьё, материалы, оборудование, услуги). Влияют на издержки, качество и доступность продукции.

### 3. Посредники
Помогают в продвижении, сбыте и распределении товаров:
- Маркетинговые агентства;
- Логистические компании;
- Розничные сети;
- Финансовые посредники (банки).

### 4. Потребители
Конечные покупатели продукции. Определяют спрос, требования к качеству, цене, сервису.

### 5. Контактные аудитории
Группы, проявляющие интерес к деятельности компании:
- СМИ;
- Государственные органы;
- Инвесторы и акционеры;
- Общественные организации;
- Местные сообщества.

## Инструменты анализа внешней среды

| Инструмент | Назначение |
|------------|------------|
| **PESTEL-анализ** | Анализ макроэкономических факторов |
| **Пять сил Портера** | Анализ конкурентной среды отрасли |
| **SWOT-анализ** | Сопоставление внешних и внутренних факторов |
| **ETOM-анализ** | Оценка влияния каждого фактора среды |
| **Бенчмаркинг** | Сравнение с конкурентами |

## Вывод

Внешняя среда маркетинга включает макросреду (PESTEL-факторы) и микросреду (конкурентное окружение). Компания не может контролировать внешние факторы, но должна их систематически анализировать и адаптировать свою маркетинговую стратегию. Понимание внешней среды позволяет выявлять возможности и угрозы, снижать неопределённость и принимать обоснованные маркетинговые решения.
