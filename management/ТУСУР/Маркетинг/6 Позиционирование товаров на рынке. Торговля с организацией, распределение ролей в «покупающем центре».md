# 6 Позиционирование товаров на рынке. Торговля с организацией, распределение ролей в «покупающем центре»

## Определение позиционирования

**Позиционирование** — это процесс формирования чёткого, отличительного и привлекательного образа продукта, бренда или компании в сознании целевой аудитории относительно конкурентов.

**Цель позиционирования** — занять уникальное место в сознании потребителя, чётко отвечающее на вопрос: «Почему я должен выбрать именно этот продукт?».

---

## Этапы позиционирования

| Этап | Действия |
|------|----------|
| **1. Анализ продукта** | Определение ключевых характеристик, преимуществ, уникальных свойств |
| **2. Анализ конкурентов** | Изучение позиционирования конкурентов, их сильных и слабых сторон |
| **3. Определение целевой аудитории** | Сегментация и выбор целевого сегмента |
| **4. Формулирование позиции** | Создание уникального ценностного предложения (Unique Selling Proposition — USP) |
| **5. Коммуникация позиции** | Донесение позиции до целевой аудитории через маркетинговые каналы |

---

## Стратегии позиционирования

| Стратегия | Описание | Пример |
|-----------|----------|--------|
| **По выгоде** | Акцент на главном преимуществе | Volvo — безопасность |
| **По цене** | Доступный или премиальный продукт | IKEA — доступный дизайн |
| **По качеству** | Высокое качество, премиум | Rolex — роскошь |
| **По аудитории** | Фокус на конкретной группе | Dove — для женщин 40+ |
| **По конкуренту** | Сравнение с конкурентом | Avis — «Мы №2, поэтому стараемся больше» |
| **По категории** | Создание новой категории | Red Bull — энергетический напиток |
| **По условиям использования** | Ассоциация с ситуацией | Gatorade — для спортсменов |

## Карта позиционирования (Perceptual Map)

Карта позиционирования — это графическое представление восприятия брендов потребителями по двум ключевым измерениям.

**Пример: автомобильный рынок**

```
              Премиум
                 │
                 │
       Mercedes ─┼── BMW
                 │
                 │
                 │
    ─────────────┼────────────→ Надёжность
                 │
                 │
         Toyota ─┼── Honda
                 │
                 │
              Доступный
```

## Торговля с организацией (B2B-маркетинг)

### Особенности B2B-маркетинга

| Характеристика | B2C | B2B |
|----------------|-----|-----|
| **Покупатель** | Физическое лицо | Организация |
| **Мотивация** | Эмоциональная, личная | Рациональная, бизнес-цели |
| **Стоимость сделки** | Низкая | Высокая |
| **Длительность цикла** | Короткая | Долгая |
| **Количество участников** | 1–2 человека | 5–10+ человек |
| **Сложность решения** | Низкая | Высокая |
| **Отношения** | Транзакционные | Долгосрочные, партнёрские |

---

## Покупающий центр (Buying Center / Decision Making Unit — DMU)

**Покупающий центр** — это группа лиц в организации, которые участвуют в процессе принятия решения о закупке определённого товара или услуги.

### Роли в покупающем центре

| Роль | Функция | Вопрос, который они задают |
|------|---------|---------------------------|
| **Инициатор** | Предлагает или инициирует закупку | «Нам нужно это решить» |
| **Пользователь** | Будет использовать продукт | «Удобно ли мне будет работать?» |
| **Влиятель** | Влияет на решение (технические специалисты, консультанты) | «Соответствует ли это стандартам?» |
| **Принимающий решение** | Принимает окончательное решение | «Сколько это стоит и какие риски?» |
| **Покупатель** | Осуществляет закупку, оформляет документы | «Какие условия поставки и оплаты?» |
| **Контролёр** | Контролирует доступ информации (секретарь, закупщик) | «Кто может участвовать в тендере?» |

### Пример покупающего центра для закупки ERP-системы

| Роль | Должность |
|------|-----------|
| Инициатор | Генеральный директор |
| Пользователь | Руководители отделов (финансы, производство, склад) |
| Влиятель | IT-директор, external-консультант |
| Принимающий решение | Генеральный директор, финансовый директор |
| Покупатель | Отдел закупок |
| Контролёр | Финансовый директор |

---

## Стратегия работы с покупающим центром

| Этап | Действия |
|------|----------|
| **1. Идентификация** | Выявление всех участников покупающего центра |
| **2. Определение ролей** | Кто какую роль выполняет |
| **3. Анализ критериев** | Какие критерии важны для каждой роли |
| **4. Адаптация коммуникации** | Разные сообщения для разных ролей |
| **5. Взаимодействие** | Построение отношений с каждым участником |

### Сообщения для разных ролей

| Роль | Сообщение |
|------|-----------|
| Пользователь | «Продукт прост и удобен в использовании» |
| Влиятель | «Продукт соответствует техническим требованиям» |
| Финансовый директор | «Продукт обеспечивает ROI 20% за 1 год» |
| Генеральный директор | «Продукт повышает конкурентоспособность компании» |

---

## Вывод

Позиционирование — это стратегический процесс, определяющий место продукта в сознании потребителя. Успешное позиционирование требует глубокого понимания целевой аудитории и конкурентной среды.

В B2B-маркетинге ключевую роль играет покупающий центр — группа лиц, участвующих в принятии решения. Понимание ролей и мотивов каждого участника позволяет выстроить эффективную коммуникацию и увеличить вероятность продажи.
