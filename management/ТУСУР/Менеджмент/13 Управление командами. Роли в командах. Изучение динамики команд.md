# 13 Управление командами. Роли в командах. Изучение динамики команд

## Определение

**Команда** — это группа людей, объединённых общей целью, взаимодополняющих друг друга по навыкам и ролям, разделяющих ответственность за результаты и работающих в условиях взаимозависимости.

**Управление командами (Team Management)** — это процесс формирования, координации и развития команд для эффективного достижения поставленных целей.

---

## Отличие команды от группы

| Характеристика | Рабочая группа | Команда |
|----------------|---------------|---------|
| **Цель** | Индивидуальные задачи | Общая коллективная цель |
| **Ответственность** | Индивидуальная | Индивидуальная + коллективная |
| **Результат** | Сумма индивидуальных результатов | Синергетический эффект (2 + 2 > 4) |
| **Лидерство** | Формальный руководитель | Распределённое или ситуационное |
| **Роли** | Определены должностью | Динамические, взаимодополняющие |
| **Взаимодействие** | Минимальное | Активное, взаимозависимое |

---

## Типы команд в организации

| Тип | Описание | Пример |
|-----|----------|--------|
| **Функциональная** | Сотрудники одного отдела, выполняющие схожие задачи | Бухгалтерия, отдел маркетинга |
| **Кросс-функциональная** | Специалисты из разных отделов для решения комплексных задач | Проектная команда |
| **Самоуправляемая** | Команда с высокой степенью автономии, сама планирует и контролирует работу | Scrum-команда |
| **Виртуальная** | Участники распределены географически, работают удалённо | Международная проектная команда |
| **Проектная** | Создана для реализации конкретного проекта, временная | Команда запуска нового продукта |
| **Управленческая** | Руководители высшего уровня, координирующие организацию | Совет директоров, правление |

## Стадии формирования команды (модель Такмана)

**Брюс Такман** (1965) выделил четыре стадии, позже добавив пятую:

```
Forming ──> Storming ──> Norming ──> Performing ──> Adjourning
(Формирование) (Конфликтация) (Нормирование) (Работа) (Расформирование)
```

### 1. Forming (Формирование)
- Участники знакомятся, определяют цели и правила;
- Высокая зависимость от лидера;
- Неопределённость ролей и задач;
- Вежливое, осторожное общение.

**Роль руководителя:** директивная — чётко ставить цели, объяснять задачи, устанавливать правила.

### 2. Storming (Конфликтация / Бурление)
- Возникают разногласия по целям, методам, ролям;
- Конкуренция, борьба за лидерство;
- Эмоциональное напряжение;
- Формирование подгрупп.

**Роль руководителя:** наставническая — фасилитировать обсуждение, помогать разрешать конфликты, укреплять коммуникацию.

### 3. Norming (Нормирование)
- Формируются нормы и правила работы;
- Распределяются роли;
- Улучшается коммуникация и доверие;
- Возникает чувство общности.

**Роль руководителя:** поддерживающая — поощрять сотрудничество, укреплять командный дух.

### 4. Performing (Работа / Функционирование)
- Команда работает как единый механизм;
- Высокая эффективность и продуктивность;
- Самоорганизация и взаимопомощь;
- Гибкое распределение ролей.

**Роль руководителя:** делегирующая — минимум вмешательства, фокус на стратегии.

### 5. Adjourning (Расформирование)
- Завершение проекта или расформирование команды;
- Подведение итогов;
- Эмоциональное завершение отношений.

**Роль руководителя:** признание заслуг, подведение итогов, помощь в переходе к новым задачам.

## Командные роли (модель Белбина)

**Мередит Белбин** (1981) выделил 9 командных ролей, разделённых на три группы:

### Роли, ориентированные на действие

| Роль | Описание | Сильные стороны | Допустимые слабости |
|------|----------|----------------|---------------------|
| **Реализатор (Implementer)** | Превращает идеи в действия, практичен, дисциплинирован | Организованность, надёжность | Негибкость, сопротивление изменениям |
| **Доводчик (Completer Finisher)** | Контролирует детали, следит за сроками, ищет ошибки | Внимательность, тщательность | Склонность к излишнему беспокойству |
| **Шейпер (Shaper)** | Напорист, энергичен, преодолевает препятствия | Драйв, решительность | Раздражительность, может задевать чувства |

### Роли, ориентированные на работу с людьми

| Роль | Описание | Сильные стороны | Допустимые слабости |
|------|----------|----------------|---------------------|
| **Координатор (Coordinator)** | Объединяет команду, координирует, делегирует | Лидерство, умение слушать | Склонность перекладывать работу |
| **Душа команды (Teamworker)** | Поддерживает гармонию, сглаживает конфликты | Дипломатичность, эмпатия | Нерешительность в спорных ситуациях |
| **Исследователь ресурсов (Resource Investigator)** | Ищет идеи и контакты, устанавливает связи | Коммуникабельность, энтузиазм | Потеря интереса после начального этапа |

### Роли, ориентированные на мышление

| Роль | Описание | Сильные стороны | Допустимые слабости |
|------|----------|----------------|---------------------|
| **Генератор идей (Plant)** | Креативен, предлагает новые идеи и решения | Творчество, нестандартность | Рассеянность, игнорирование практических деталей |
| **Аналитик (Monitor Evaluator)** | Анализирует, оценивает, взвешивает варианты | Объективность, стратегическое мышление | Отсутствие энтузиазма, излишняя критичность |
| **Специалист (Specialist)** | Обладает глубокими знаниями в узкой области | Экспертиза, преданность делу | Узость взгляда, не видит общей картины |

### Принципы распределения ролей
- Каждый участник может выполнять 2–3 роли (основную и вспомогательные);
- Команда должна охватывать все 9 ролей для максимальной эффективности;
- Чрезмерное количество «генераторов идей» без «реализаторов» приводит к невыполнению задач;
- Отсутствие «аналитика» повышает риск ошибочных решений.

## Динамика команд

### Факторы, влияющие на командную динамику

| Фактор | Влияние |
|--------|---------|
| **Размер команды** | Оптимальный размер — 5–9 человек. Больше — снижение эффективности, меньше — нехватка ресурсов |
| **Состав** | Разнообразие навыков, опыта и стилей мышления |
| **Цель** | Чёткая, измеримая, разделяемая всеми участниками |
| **Лидерство** | Стиль руководства, соответствующий стадии развития команды |
| **Коммуникация** | Открытость, обратная связь, прозрачность |
| **Доверие** | Основа эффективного взаимодействия |
| **Корпоративная культура** | Поддержка командной работы, поощрение сотрудничества |

### Признаки эффективной команды

| Признак | Описание |
|---------|----------|
| **Общая цель** | Чёткое понимание и принятие целей всеми участниками |
| **Взаимное доверие** | Открытость, честность, поддержка |
| **Эффективная коммуникация** | Свободный обмен информацией, обратная связь |
| **Распределённое лидерство** | Участники проявляют инициативу в рамках своих ролей |
| **Конструктивные конфликты** | Разногласия по задачам, а не по личностям |
| **Принятие решений** | Совместные решения, консенсус |
| **Взаимная ответственность** | Каждый отвечает за общий результат |
| **Адаптивность** | Быстрая реакция на изменения |

### Признаки дисфункциональной команды

| Проблема | Проявления |
|----------|------------|
| **Отсутствие доверия** | Скрытность, страх показаться уязвимым |
| **Боязнь конфликтов** | Избегание обсуждений, искусственная гармония |
| **Отсутствие обязательств** | Непонимание целей, пассивность |
| **Избегание ответственности** | Перекладывание вины, низкие стандарты |
| **Невнимание к результатам** | Акцент на статусе, а не на общей цели |

## Методы повышения эффективности команд

| Метод | Описание |
|-------|----------|
| **Team-building** | Тренинги и мероприятия для укрепления командного духа |
| **Фасилитация** | Профессиональное ведение командных обсуждений |
| **Ретроспектива** | Регулярный анализ работы команды (что сделали хорошо, что улучшить) |
| **Ротация ролей** | Периодическая смена ролей для развития навыков |
| **Обучение** | Повышение компетенций команды в целевых областях |
| **Прозрачная система KPI** | Понятные критерии оценки командных результатов |
| **Регулярная обратная связь** | Постоянная коммуникация о качестве работы |

## Вывод

Управление командами — это ключевая компетенция современного менеджера. Эффективная команда создаётся не стихийно, а проходит через последовательные стадии развития (формирование, конфликтация, нормирование, работа). Успех команды зависит от правильного распределения ролей (модель Белбина), создания атмосферы доверия, открытой коммуникации и взаимной ответственности.

**Ключевые факторы успеха команды:**
- Чёткая и разделяемая цель;
- Сбалансированный состав (все 9 ролей Белбина);
- Эффективный лидер, адаптирующий стиль к стадии развития;
- Открытая коммуникация и конструктивное разрешение конфликтов;
- Признание и вознаграждение командных результатов.
