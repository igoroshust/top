# 17 Состав и характеристика внутренней среды организации

## Определение

**Внутренняя среда организации** — это совокупность элементов, факторов и условий внутри компании, которые формируются под влиянием управленческих решений и определяют возможности организации в достижении целей. Внутренняя среда включает ресурсы, процессы, структуру, культуру и персонал организации.

**Цель анализа внутренней среды** — выявить сильные и слабые стороны компании для эффективного использования возможностей внешней среды и минимизации угроз.

---

## Состав внутренней среды

Внутренняя среда организации традиционно рассматривается как совокупность пяти основных функциональных областей (модель 5М или 5S):

```
                    ┌─────────────────────┐
                    │   Персонал (Staff)  │
                    ├─────────────────────┤
                    │    Финансы (Money)  │
                    ├─────────────────────┤
                    │  Производство (Ops) │
                    ├─────────────────────┤
                    │  Маркетинг (Market) │
                    ├─────────────────────┤
                    │   Структура (Org)   │
                    └─────────────────────┘
```

## 1. Производство (управление операциями)

### Составляющие

| Элемент | Описание |
|---------|----------|
| **Объём и структура производства** | Количество и номенклатура выпускаемой продукции |
| **Производственные мощности** | Оборудование, площади, резервы |
| **Технология** | Способы производства, автоматизация |
| **Качество** | Системы контроля качества (TQM, ISO) |
| **Запасы** | Сырьё, материалы, незавершённое производство |
| **Логистика** | Складское хозяйство, транспортировка |
| **Интеллектуальная собственность** | Патенты, лицензии, ноу-хау |

### Характеристики

| Показатель | Описание |
|------------|----------|
| Издержки | Себестоимость единицы продукции |
| Производительность | Выработка на единицу ресурса |
| Загрузка мощностей | Фактическое использование оборудования |
| Качество | Доля брака, рекламации |

## Взаимосвязь элементов внутренней среды

Внутренняя среда — это **система**, где изменение одного элемента влияет на другие:

| Изменение | Влияние на другие элементы |
|-----------|---------------------------|
| Внедрение новой технологии (производство) | Может потребовать обучения персонала (кадры), дополнительных инвестиций (финансы), изменения ценообразования (маркетинг) |
| Сокращение персонала (кадры) | Снижение объёмов производства (производство), уменьшение затрат (финансы) |
| Увеличение маркетингового бюджета (маркетинг) | Рост продаж (производство), увеличение доходов (финансы) |

## Анализ внутренней среды

### Инструменты анализа

| Инструмент | Назначение |
|------------|------------|
| **SWOT-анализ** | Оценка сильных и слабых сторон (внутренняя среда) в сопоставлении с возможностями и угрозами (внешняя среда) |
| **SNW-анализ** | Оценка внутренней среды по трём категориям: S (Strength) — сильная, N (Neutral) — нейтральная, W (Weakness) — слабая |
| **VRIO-анализ** | Оценка ресурсов: Valuable (ценный), Rare (редкий), Immutable (труднокопируемый), Organized (организованный) |
| **Цепочка ценности (Портер)** | Анализ внутренних процессов, создающих ценность для клиента |
| **Финансовый анализ** | Оценка ликвидности, рентабельности, устойчивости |

### Этапы анализа внутренней среды

| Этап | Действия |
|------|----------|
| 1. Сбор данных | Финансовая отчётность, производственные показатели, опросы персонала, отзывы клиентов |
| 2. Систематизация | Группировка по функциональным областям |
| 3. Оценка | Выявление сильных и слабых сторон по каждой области |
| 4. Приоритизация | Определение наиболее значимых факторов |
| 5. Выводы | Формирование рекомендаций для стратегического планирования |

## Взаимосвязь внутренней и внешней среды

| Аспект | Описание |
|--------|----------|
| **Ресурсы** | Внешняя среда предоставляет ресурсы (сырьё, финансы, персонал), которые поступают во внутреннюю среду |
| **Возможности и угрозы** | Изменения внешней среды создают возможности или угрозы для внутренней среды |
| **Адаптация** | Внутренняя среда должна адаптироваться к изменениям внешней |
| **SWOT** | Сильные и слабые стороны (внутренние) сопоставляются с возможностями и угрозами (внешними) |

---

## Вывод

Внутренняя среда организации — это сложная система взаимосвязанных элементов, включающая производство, персонал, финансы, маркетинг и организационную структуру. Анализ внутренней среды позволяет:

1. Выявить сильные и слабые стороны компании;
2. Оценить ресурсный потенциал;
3. Определить направления для улучшения;
4. Сформировать основу для стратегического планирования.

**Ключевые принципы управления внутренней средой:**
- Комплексный подход (учёт всех элементов);
- Системное видение (понимание взаимосвязей);
- Постоянный мониторинг и адаптация;
- Ориентация на развитие и улучшение.
