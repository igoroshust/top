# 18 Организационная культура. Типы организационных культур. Культура и ценности

## Определение

**Организационная (корпоративная) культура** — это система коллективно разделяемых ценностей, убеждений, норм, правил и моделей поведения, которые формируют внутреннюю среду организации и определяют способ взаимодействия сотрудников между собой и с внешним окружением.

Организационная культура — это «душа» организации, то, как «принято делать дела» в данной компании.

---

## Уровни организационной культуры (модель Э. Шейна)

| Уровень | Описание | Примеры |
|---------|----------|---------|
| **Артефакты** | Видимые, наблюдаемые элементы | Офисный дизайн, дресс-код, язык, логотип, ритуалы |
| **Провозглашаемые ценности** | Официально заявленные принципы и стратегии | Миссия, кодекс этики, девизы |
| **Базовые предположения** | Глубинные, неосознаваемые убеждения | Отношение к людям, к работе, к изменениям |

```
Артефакты (видимо, но трудно расшифровать)
        │
        ▼
Провозглашаемые ценности (осознаваемые)
        │
        ▼
Базовые предположения (неосознаваемые, фундаментальные)
```

## Функции организационной культуры

| Функция | Описание |
|---------|----------|
| **Охранная** | Защита от проникновения нежелательных влияний |
| **Интеграционная** | Объединение сотрудников вокруг общих целей |
| **Регулятивная** | Установление норм и правил поведения |
| **Адаптационная** | Помощь новым сотрудникам в освоении |
| **Мотивационная** | Создание чувства причастности и гордости |
| **Идентификационная** | Формирование чувства принадлежности к организации |
| **Имиджевая** | Формирование образа компании во внешней среде |

## Типы организационных культур (классификации)

### 1. Типология Ч. Хэнди

| Тип | Метафора | Характеристика | Пример |
|-----|----------|----------------|--------|
| **Культура власти** | «Паутина» | Централизация, лидер — сильная личность, мало правил | Малый бизнес, предпринимательские структуры |
| **Культура роли** | «Храм» | Чёткие правила, процедуры, иерархия, функциональность | Госучреждения, банки |
| **Культура задачи** | «Сеть» | Командная работа, фокус на решении задач, гибкость | IT-компании, R&D |
| **Культура личности** | «Созвездие» | Автономия, профессионалы ценятся выше организации | Адвокатские конторы, консалтинг |

### 2. Типология К. Камерона и Р. Куинна (конкурирующие ценности)

Основана на двух измерениях: **гибкость — стабильность** и **внешний — внутренний фокус**.

```
                Гибкость
                    │
    ┌──────(Клан)───┼───(Адхократия)──────┐
    │               │                      │
    │               │                      │
Внутр.│─────────────┼──────────────┤Внешн.
фокус│             │              │фокус
    │               │                      │
    │               │                      │
    └──────(Иерархия)─┼──(Рынок)──────────┘
                    │
                Стабильность
```

| Тип | Фокус | Характеристика | Лидер |
|-----|-------|----------------|-------|
| **Клан** | Внутренний, гибкость | Семья, teamwork, лояльность, традиции | Наставник, родитель |
| **Адхократия** | Внешний, гибкость | Инновации, творчество, риск, динамика | Новатор, предприниматель |
| **Рынок** | Внешний, стабильность | Конкуренция, результат, эффективность | Жёсткий, требовательный |
| **Иерархия** | Внутренний, стабильность | Правила, процедуры, структура, контроль | Координатор, администратор |

### 3. Типология Р. Акоффа

| Тип | Степень вовлечения | Отношение к власти |
|-----|-------------------|-------------------|
| **Автократическая** | Низкое | Власть сосредоточена наверху |
| **Бюрократическая** | Низкое | Власть распределена по правилам |
| **Консультативная** | Высокое | Руководитель советуется с подчинёнными |
| **Партисипативная** | Высокое | Коллективное принятие решений |

## Культура и ценности

### Определение

**Ценности** — это разделяемые убеждения о том, что является важным, правильным, желательным в организации. Они составляют ядро организационной культуры.

### Иерархия ценностей

| Уровень | Описание | Примеры |
|---------|----------|---------|
| **Базовые ценности** | Фундаментальные, неизменные принципы | Честность, уважение |
| **Стратегические ценности** | Определяют направление развития | Инновации, лидерство |
| **Операционные ценности** | Регулируют повседневное поведение | Пунктуальность, качество |

### Примеры корпоративных ценностей известных компаний

| Компания | Ценности |
|----------|----------|
| **Google** | Фокус на пользователе, инновации, «не будь злым» |
| **Apple** | Простота, креативность, совершенство дизайна |
| **Amazon** | Клиентоцентричность, одержимость инновациями, долгосрочное мышление |
| **Toyota** | Качество, непрерывное улучшение (кайдзен), уважение к людям |
| **Zappos** | Удивлять клиентов, приветствовать изменения, создавать командный дух |

### Как ценности влияют на управление

| Аспект управления | Влияние ценностей |
|-------------------|-------------------|
| **Подбор персонала** | Найм сотрудников, разделяющих ценности |
| **Мотивация** | Признание поведения, соответствующего ценностям |
| **Принятие решений** | Ценности как критерий выбора |
| **Коммуникация** | Язык, стиль общения |
| **Лидерство** | Поведение руководителя как пример |

## Формирование и поддержание организационной культуры

### Факторы, влияющие на формирование культуры

| Фактор | Описание |
|--------|----------|
| **Основатели и лидеры** | Их ценности, стиль, пример |
| **История организации** | Традиции, ключевые события |
| **Размер организации** | Влияние на формализацию и иерархию |
| **Отрасль** | Специфика, рискованность |
| **Внешняя среда** | Национальная культура, законодательство |

### Методы поддержания культуры

| Метод | Описание |
|-------|----------|
| **Селекция персонала** | Отбор по соответствию культуре |
| **Адаптация новых сотрудников** | Погружение в культуру, наставничество |
| **Обучение** | Формирование ценностей через тренинги |
| **Ритуалы и традиции** | Регулярные события (планёрки, корпоративы) |
| **Легенды и герои** | Истории о выдающихся сотрудниках |
| **Система мотивации** | KPI, соответствующие ценностям |
| **Внутренние коммуникации** | Трансляция ценностей во всех сообщениях |

## Сильная и слабая организационная культура

| Характеристика | Сильная культура | Слабая культура |
|----------------|-----------------|-----------------|
| **Разделяемость** | Ценности широко разделяются | Ценности размыты |
| **Согласованность** | Ценности непротиворечивы | Есть внутренние противоречия |
| **Влияние на поведение** | Высокое | Низкое |
| **Лояльность** | Высокая | Низкая |
| **Эффективность** | Способствует достижению целей | Препятствует |

## Вывод

Организационная культура — это фундаментальный элемент управления, влияющий на все аспекты деятельности организации: от стратегии до повседневного поведения сотрудников. Сильная, согласованная культура, разделяемая сотрудниками, становится источником конкурентного преимущества.

**Ключевые аспекты управления организационной культурой:**
- Осознанное формирование ценностей, соответствующих стратегии;
- Последовательное подкрепление ценностей через все HR-процессы (подбор, обучение, мотивация);
- Роль лидеров как носителей и трансляторов культуры;
- Регулярная диагностика и корректировка культуры;
- Создание условий, в которых сотрудники могут разделять и реализовывать ценности в своей работе.
